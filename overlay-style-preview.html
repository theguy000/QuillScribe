Overlay Style Direction

These are visual-only concepts for the recording overlay. My recommendation is to keep one polished default instead of multiple settings: quiet glass for composited desktops, with a solid fallback using the same shape and spacing.

Recommended Default

Use Quiet Glass when transparency/compositing is available. It feels native, stays legible, and does not compete with the app content.

Fallback

Use the same dimensions with a solid background when blur/transparency is not reliable, especially on Linux/X11 desktops.

Avoid

Avoid neon-heavy borders, strong glow, and too many style choices. The overlay should communicate recording state without becoming a theme picker.
