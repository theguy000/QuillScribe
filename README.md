# QuillScribe

<p align="center">
  <img src="public/logo.svg" alt="QuillScribe Logo" width="280" />
</p>

A voice-powered transcription workspace built with **Svelte 5**, **Vite**, and **Tauri 2**.

> **Work in progress** — actively under development.

## Tech Stack

- **Frontend:** Svelte 5 + Vite
- **Desktop:** Tauri 2
- **Backend:** Rust

## Getting Started

```bash
npm install
npm run dev
```

To build the Tauri desktop app:

```bash
npm run tauri dev
```
